# Carom

Carom is a fast, local paddle duel built around spin and bank shots. Play solo against the computer or share the keyboard in local Versus. The fixed field, paired obstacles, and paddle driven spin make every rally a contest of angles as much as timing.

## Install

```sh
npm ci
```

## Run in development

```sh
npm run dev
```

## Build for production

```sh
npm run build
```

Vite writes the self-contained static site to `dist/`. Serve that directory from the root of any static host.

## Controls

- **Solo:** W/S or ↑/↓ moves your left paddle; the computer guards the right.
- **Versus:** W/S controls the left paddle and ↑/↓ controls the right.
- **Enter / Space:** select menu items.
- **P / Escape:** pause or resume.
- **M:** toggle sound.
- Menus also respond to pointer and touch.
